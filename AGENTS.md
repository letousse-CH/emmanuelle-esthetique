# Mode d'Opération Équipe d'Agents IA

Ce projet est configuré pour faire intervenir 4 sous-agents IA spécialisés en synergie permanente :

- **`lead_strategist`** : Vision produit, didactique des interfaces (0 jargon, 1-2-3), contrôle de conformité.
- **`fullstack_architect`** : Routes d'API Next.js, Supabase, auto-migration SQL, gestion multi-sites.
- **`ui_ux_designer`** : UX/UI, Tailwind CSS, animations Framer Motion, cartes calendrier, accordéons, charte admin.
- **`qa_bug_hunter`** : Audit TypeScript, tests de build Next.js (`npm run build`), zéro-erreur avant push.

À chaque nouvelle conversation, cette équipe est automatiquement initialisée et activée.
